「Webコンテンツ作成」の成果

本テーマについて

情報工学の専門科目の基礎知識を応用して実践的な能力を習得する。またwebコンテンツ作成ではHTML,CSS,JavaScriptを段階的に覚えていき、イベント駆動や外部サーバーとの通信処理を実現し検索ページを作成できるようになった上でプロジェクト課題とindex.htmlを初めとした演習や課題を行いたい。

プロジェクト課題について

本プログラムは、選択したジャンルに応じた飲食店情報を表示するWebアプリケーションです。画面の選択肢からジャンルを選んでボタンを押すと、JavaScriptの関数が実行されます。取得したJSON形式のデータは、DOM操作によって動的にページへ組み込まれます。具体的には、要素を新しく生成して店名やアクセス、料金などの情報を流し込み、画面の適切な位置に挿入しています。検索を行うたびに前回の表示内容を削除するため、常に最新の4件が正しく表示されます。また、CSSのグリッドレイアウトを用いて結果を2列に綺麗に整列させています。

プロジェクト課題で作成したページ: project.html

数当てゲーム

本プログラムは、JavaScriptを用いてブラウザ上で1から10までの整数を当てる「数当てゲーム」を実装したものです。ページが読み込まれた際に、Math.random関数を用いて1から10の範囲でランダムな正解番号（乱数）を1つ自動生成します。ユーザーが画面上の入力欄に数値を入力して「回答」ボタンを押すと、イベントリスナーによりhantei関数が呼び出されます。関数内では、querySelectorを用いて入力値を取得し、条件分岐を使って「正解」や「もっと大きい」「もっと小さい」といった判定結果を導き出します。そして、DOM操作により、現在の予想回数、入力した数値、および判定メッセージをリアルタイムに画面へ反映させます。ゲームは最大3回までの回数制限を設けて制御しています。

各授業回の学習事項

第1回 WWW と HTML

第1回の講義では、WWWの仕組みやURL、HTTPなど、Webページが表示される仕組みについて学んだ。またHTMLの基本構造を理解し、見出しや段落、リスト、ハイパーリンク、画像の埋め込みといった要素を用いて簡単なWebページを作成する方法を学習した。

演習の成果: 演習1-4: HTMLのさまざまな要素

第2回 CSS による Web ページの装飾

第2回の講義では、CSSを用いたWebページの装飾方法について学んだ。セレクタやプロパティによる見た目の変更、リンクやリストの装飾、ボックスモデルやレイアウトの基本、さらに開発者ツールを用いたCSSのデバッグ方法について学習した。

演習の成果: 演習2-3: ウェブブラウザ説明ページの装飾

第3回 JavaScript の基本

第3回の実験では、JavaScriptの基本的な文法やJavaとの違いについて学んだ。特に、変数宣言や関数、オブジェクトの使い方が印象に残った。また、コンソールやデバッガを利用したデバッグ方法の重要性も理解できた。

演習の成果: 演習3-6: オブジェクトの参照

第4回 イベント処理と DOM

今回の講義では、input要素やボタンを使った入力フォームの作成方法に加え、DOMを利用してHTML要素の検索やテキストの変更を行う方法を学んだ。イベント処理によってページに動きを付けられることが分かり、Webページ作成の幅が広がったと感じた。

演習の成果: 演習4-10: 足し算ページ

第5回 DOMの高度な機能について

第5回では、DOMを利用した要素の作成・変更・削除について学んだ。JavaScriptからHTMLを操作してページの内容を動的に変化させる方法を理解できた。特に、要素を新しく追加したり削除したりする機能は、Webページ作成の幅を広げる重要な技術だと感じた。

演習の成果: 演習5-7: DOMプログラミング

第6回 プロジェクト課題を完成させよう

第6回では、プロジェクト課題の完成に向けて検索機能や結果表示の方法を考えた。また、Ajax通信とaxiosを用いた非同期通信について学び、ページを再読み込みせずにサーバとデータのやり取りができる仕組みを理解できた。Webアプリ開発に役立つ内容だと感じた。

工夫点，苦心点，強調点，感想

Index.htmlを作る上で工夫したことはまずレイアウトの色合いです。みやすくなるように色を分けてかつ大学の授業に合うようにシンプルなものにしました。また一番上の見出しの部分は誰でもみやすいように一般的なゴシック体風のフォントにしており、「本テーマについて」や「数当てゲーム」の方は筆記体のようなフォントにし、少し柔らかい印象をイメージしました。次に工夫した点は強調点でもあるのですが「本テーマについて」の背景の色の濃度を右に向かって濃くすることで文字の方の印象を強く持たせることです。これにより色が邪魔で文章が見にくくなることを避けました。また文章の色も何種類か試しましたが見出しは青、文章は黒というシンプルな形に落ち着きました。苦心点としてはサイトを全体的に見た時に個性が出ていないと感じました。また人に見てもらうことを考えたすぎた結果派手さが少し足りないかなと思いました。次にこの授業全体の感想です。第一回目ではWebページの基本的な記述方法とHTML について学びました。Visual Studio Codeはプログラミングの授業でつかっけいましたがHTMLは初めてで、新しい宣言も多く大変でした。第二回目の授業ではWebページのレイアウトを指定するためのCSSについて学びました。HTML が最初に与えられて次にその装飾をする CSSという仕組みは面白く今まで一つのプログラムで完結していたのでとても斬新でした。またウェブ開発ツールのコンソールやインスペクターは個人的にターミナルより使いやすかったです。第3回はインタラクティブなページを作るためのJavaScript プログラミングについて学びました。if文など知っているものもありましたが、Web ページ上で複雑な機能を実現するプログラミングであるがゆえ理解をするのはやはり自分には難しかったです。第4回目は3回目の延長のようでしたがDOMにより、Web コンテンツの内容を読み取ったり、コンテンツに変更を加えたりする処理が書けるようになるのは、すごく便利でそれによりwebページがより良いものになるのだと理解しました。第5回目はDOMの続きで、要素の新規作成や要素の編集を主に行いました。コンソールを使い新規要素を HTML に配置したりli要素を削除した時は動きがすぐに反映されてスムーズで演習問題や課題をしている時が充実した時間になりました。最後の授業は外部サーバとの通信処理を実現しプロジェクト課題を完成させる授業でした。Ajax通信のプログラムは難しかったですが、練習6-1はコンソールの出力とjsを見比べてみると面白かったです。全体を通してwebサイトの作りを内側から実践的に取り組めて面白かったです。
